# Heirloom v0.1.0 — first tagged release

> **ARCHIVED - historical record (2026-08-13).** Describes a superseded design or
> a completed task brief. Nothing here describes current behavior. The live
> documentation set is indexed in [../../README.md](../../README.md).
> Why: Release notes for the v0.1.0 tag - historical by nature.

A terminal AI coding agent you own: bring your own API key (DeepSeek, OpenAI,
OpenRouter, Groq, Ollama), one readable TypeScript codebase, no telemetry, no
account. Sessions are plain JSONL under your home directory.

## Highlights
- **Claude Code-style rendering** — committed output flushes once into native
  terminal scrollback (mouse wheel, search, copy); only a ~6-row live region
  repaints, so slow emulators (IntelliJ) stay stable
- **Shadow-git checkpoints + /undo** — every file-editing turn is restorable,
  without touching your real repo; checkpointing is fully off the main thread
- **Sessions** — /resume, /continue, per-project persistent prompt history
- **Skills & modes** — /skills loads reusable instruction packs; YAML modes
- **Self-diagnosis** — `heirloom doctor` (and /doctor in-session): provider,
  refresh profile, DEC-2026 terminal probe; `HEIRLOOM_PROFILE=1` captures a
  CPU profile + event-loop stall log for perf reports

## Fixed on the road here
- Main-thread freeze root-caused by profile (execSync in checkpoints) and fixed
- Full-frame repaint flicker chain (incremental rendering, cadence, layout)
- Bracketed paste, multi-line echo, /skills layout, history recall past commands

## Known limits (0.1 honesty)
- Verified on macOS only; Linux/Windows untested
- Single-tester validation; the selection surfaces are converging on a shared
  component but 11 still differ cosmetically
- npm publish intentionally disabled (`private: true`) — install from git

## Install
    git clone https://github.com/amenski/heirloom-agent && cd heirloom-agent
    npm install && npm run build && npm link
    heirloom doctor   # verify your terminal + keys
